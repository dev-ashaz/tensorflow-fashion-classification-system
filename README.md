TensorFlow Fashion Classification System
Overview
A computer vision classification system built using TensorFlow and Deep Learning to identify clothing categories from image data.

Technologies Used
Python
TensorFlow
NumPy
Matplotlib
Google Colab
Machine Learning Concepts
Data Modelling
Neural Networks
Classification
Deep Learning
Predictive Systems
Dataset
Fashion-MNIST Dataset

60,000 training images
10,000 test images
10 clothing categories
Results
The model achieved approximately 87% test accuracy on unseen data.
